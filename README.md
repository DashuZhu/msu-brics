# МГУ–ППИ · Бизнес-день 2026

Одностраничный сайт бизнес-дня **22 ноября 2026 года, Шэньчжэнь**.

Русская, английская и китайская версии, финальная программа, секция о внедрении ИИ, адаптивная вёрстка и сохранение даты в календарь. Без внешних библиотек, шрифтов, аналитики и платных сервисов.

## Содержание

- `index.html` — структура, стили и метаданные.
- `content.js` — тексты RU / EN / 中文, компании и программа.
- `app.js` — переключение языков, раскрытие программы и календарь.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

Сайт можно перенести на любой статический хостинг, загрузив файлы сайта вместе с изображениями. Домен подключается отдельно после согласования DNS. Сервер и база данных для текущей версии не требуются.

## Просмотр локально

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173/`.

Языковые ссылки: `?lang=ru`, `?lang=en`, `?lang=zh`. Выбор языка также сохраняется в браузере.
